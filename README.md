**⚡ 01. Distributed Key-Value Store**

A Dynamo-style, leaderless distributed key-value database implemented as a 5-node cluster.

- Consistent hashing with 128 virtual nodes for distributed key placement.
- Quorum-based reads and writes: N=3, W=2, R=2.
- Heartbeat-based failure detection, read repair and tombstones.
- Write-ahead logging with fsync, crash recovery and compaction.
- Sorted index supporting prefix scans in O(log n + k) per node.
- Returns HTTP 503 when quorum is unavailable rather than serving stale data.

**Testing:** 16 passing tests, including end-to-end tests with real processes and node failures. Load testing achieved zero errors across 504 requests with all 5 nodes; 99.78% success with one node down.
